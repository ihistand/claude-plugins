A — Single Page, Plugin Cards

Top nav links to each plugin section. All content scrolls on one page. Simple, fast to build.

Pros

  • No routing needed
  • Easy to CMD+F search
  • Works without a server

Cons

  • Gets long as plugins grow
  • Less structured per-plugin

B — Sidebar Nav + Content Pane

Left sidebar with plugin/section tree. Content loads in main pane. Classic docs layout (like Docusaurus/Stripe).

Pros

  • Scales well
  • Easy to navigate deep content
  • Familiar for devs

Cons

  • More JS to wire up
  • More initial complexity

C — Hub + Detail Pages

Landing page with plugin grid. Click a plugin to see its dedicated full-page docs. Client-side routing (hash-based).

Pros

  • Clean landing experience
  • Each plugin gets full page
  • Easy to extend

Cons

  • More pages to maintain
  • Needs hash routing
