# prd-toolkit

prd-toolkit moved to https://github.com/PRDAnvil/prd-toolkit on 2026-11-10. If you installed it from this marketplace, remove that copy first, or both load: `claude plugin uninstall prd-toolkit@ihistand`, at every scope it is installed. Then install it with `/plugin marketplace add PRDAnvil/prd-toolkit` and `/plugin install prd-toolkit@prdanvil`, and run `/reload-plugins`.

Its history up to the move is in this repository's git log, and in full in the new one.
