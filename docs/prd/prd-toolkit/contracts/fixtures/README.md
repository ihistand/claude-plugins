# Fixtures

Files here are test data, named by path without extension (`orders/one_existing`). Use CSV, YAML or
JSON, one directory per table. Data is synthetic only: no real emails, names, phone numbers or SSNs.
Every fixture is also listed in `testing.md` under Fixtures with how to load and tear it down.
